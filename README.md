## 模块协作

项目后续按“主体线程 + 模块分支线程”的方式推进：

- 主体线程负责集成、稳定性、版本目标和共享文件。
- 分支线程只负责战斗核心、地图波次、UI体验、美术资源、策划文档中的一个模块。
- 共享文件如 `project.godot`、`scenes/game.tscn`、`scripts/game_manager.gd` 默认由主体线程把关。

详细边界见 `docs/开发模块分工.md`。

## 快速开始

1. 用 Godot 4.6.3 打开 `project.godot`
2. 运行主场景 `scenes/main_menu.tscn`
3. 点击「开始游戏」进入第一关

## 当前原型

当前版本先打磨基础塔防闭环，不急于扩展七大纪元内容。

- **核心玩法：** 22×13 网格塔防，点击格子建塔，敌人使用 A* 动态寻路。
- **关卡流程：** 5 张封禁区地图，主菜单可选关，游戏内可返回菜单，胜负后进入关卡结算页。
- **波次系统：** 每关 10 波，支持提前开启下一波和多波并行。
- **防御塔：** 量子棱镜、观测棱镜、虚粒子阱，支持升级、出售、分级外观变化和差异化升级效果。
- **图鉴/暂停：** 主菜单和暂停弹窗可查看防御塔、敌人详细图鉴，图鉴含敌人与塔升级形态预览，局内塔菜单保留简洁信息。
- **建造反馈：** 选择防御塔后显示跟随鼠标的建造影子，不可建造位置以红色提示。
- **敌人：** 5 档数值敌人；前两档已接行走动画，其余仍为几何占位。
- **遗留内容：** `scripts/enemies/virtual_particle.gd` 等量子主题敌人脚本暂未接入当前波次，后续可按方向选择复用或清理。
